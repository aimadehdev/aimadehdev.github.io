Sobre Mí

Capacidad demostrada para moverme con soltura entre el código de alto nivel y el diagnóstico físico de máquinas, redes y circuitos.

Soy Aimad El Hammouti, un perfil técnico singular con base en Vic (Barcelona). En un mercado donde el software y el hardware suelen estar desconectados, mi trayectoria une lo mejor de ambos mundos: la disciplina del desarrollo corporativo en NTT DATA —diseñando microservicios, deduplicación de alertas y orquestación Cloud— con una amplia experiencia práctica en entornos industriales, electrónicos y de infraestructuras críticas.

He manipulado circuitos y componentes bajo normativa electrostática ESD en ELAUSA, ensamblado y cableado luminarias y placas solares en Novatilu, coordinado líneas de montaje y operado transpaletas y maquinaria de expediciones en Ofitres, y mantenido cuadros eléctricos y armarios Rack de comunicaciones en la reforma de la UCI del Hospital de Vic.

Tanto si se trata de programar una API escalable en Laravel / Python / .NET con integración de IA, como si se requiere montar un servidor, tirar cableado estructurado, reparar un automatismo o gestionar el ritmo de una línea de producción, aplico un enfoque riguroso, limpio y orientado a resultados.

Bluetooth Battery Monitor (Control Bluetooth)

Herramienta residente en la bandeja del sistema (System Tray) para la monitorización en tiempo real del nivel de batería y estado de periféricos inalámbricos (ratones, teclados, auriculares).

  • Interfaz gráfica responsiva con flyout desplegable desarrollada con Python y PySide6 / Qt.
  • Comunicación de bajo nivel con la pila Bluetooth de Windows mediante WinRT.
  • Implementación inversa de comandos del protocolo Logitech HID++.
  • Optimización extrema: ultra bajo consumo (< 20 MB RAM, 0% CPU en reposo).
Python PySide6 / Qt WinRT Logitech HID++ MSIX

Mezclador de sonido avanzado integrado de forma nativa en la barra de tareas de Windows, permitiendo controlar volúmenes individuales por aplicación o pestaña de navegador.

Python PySide6 WASAPI Windows Core Audio Chrome Extension
