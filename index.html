GeoStock 3D — Inteligencia Geopolítica y Mercados

Plataforma fullstack interactiva que visualiza eventos geopolíticos mundiales y su correlación de impacto con los mercados financieros proyectados sobre un globo terráqueo 3D en tiempo real.

  • Arquitectura de microservicios con backend en Python / FastAPI y Docker.
  • Ingesta y scraping concurrente de noticias internacionales con persistencia en MongoDB.
  • Integración de Google Gemini API para categorización semántica y análisis contextual.
  • Visualización de mapas de calor y eventos 3D interactivos mediante Three.js.
Python FastAPI Three.js Docker MongoDB Google Gemini API
Desktop (.NET 8) & Mobile (Kotlin) ● Empaquetado

Reproductor Multimedia IPTV de Alto Rendimiento

Solución multiplataforma para reproducción de streaming en vivo de baja latencia con aceleración por hardware, versión de escritorio para Windows y versión nativa móvil para Android.

  • Escritorio en C# (.NET 8) con interfaz moderna fluida en WinUI 3 y WPF.
  • App nativa Android desarrollada en Kotlin con Jetpack Compose y Media3 / ExoPlayer.
  • Soporte de protocolos Xtream Codes, listas M3U8 y sincronización de Guía EPG.
  • Empaquetado listo para distribución en formato MSIX para Windows y APK para Android.
C# (.NET 8) WinUI 3 Kotlin Jetpack Compose Media3 / ExoPlayer MSIX
Desktop Windows Utility ● Microsoft Store Ready

Bluetooth Battery Monitor (Control Bluetooth)

Herramienta residente en la bandeja del sistema (System Tray) para la monitorización en tiempo real del nivel de batería y estado de periféricos inalámbricos (ratones, teclados, auriculares).

  • Interfaz gráfica responsiva con flyout desplegable desarrollada con Python y PySide6 / Qt.
  • Comunicación de bajo nivel con la pila Bluetooth de Windows mediante WinRT.
  • Implementación inversa de comandos del protocolo Logitech HID++.
  • Optimización extrema: ultra bajo consumo (< 20 MB RAM, 0% CPU en reposo).
Python PySide6 / Qt WinRT Logitech HID++ MSIX
Audio API & Sistema ● Finalizado

SoundTray — Taskbar Audio Controller

Mezclador de sonido avanzado integrado de forma nativa en la barra de tareas de Windows, permitiendo controlar volúmenes individuales por aplicación o pestaña de navegador.

  • Interacción directa con la Windows Core Audio API (WASAPI / Endpoint Volume).
  • Control independiente de volumen por proceso o ventana en ejecución.
  • Desarrollo de un puente bidireccional (browser bridge) para silenciar pestañas de navegador.
  • Empaquetado profesional como aplicación de escritorio nativa para Windows.
Python PySide6 WASAPI Windows Core Audio Chrome Extension
