# Portfolio Profesional - Aimad El Hammouti

Este es el repositorio del sitio web de portfolio profesional de **Aimad El Hammouti**, desplegado de forma gratuita en [GitHub Pages](https://pages.github.com/).

🌐 **Sitio Web en Vivo:** [https://aimadehdev.github.io](https://aimadehdev.github.io)

---

## 🚀 Tecnologías Utilizadas
- **HTML5 Semántico & Accesible**
- **CSS3 Moderno** (Diseño responsivo, Glassmorphism, temas Claro / Oscuro con variables CSS, animaciones suaves)
- **JavaScript Vanilla** (Interacción de temas, filtros dinámicos de proyectos, observador de scroll y copiado interactivo de correo)
- **Alojamiento:** GitHub Pages con dominio gratuito `aimadehdev.github.io` y certificado SSL/HTTPS automático.

## 📁 Estructura del Proyecto
```
aimadehdev.github.io/
├── assets/
│   ├── avatar.jpg                 # Foto de perfil
│   └── cv_aimad_el_hammouti.pdf   # Currículum Vitae descargable
├── index.html                     # Página principal del portfolio
├── style.css                      # Estilos y temas
├── script.js                      # Interactividad y lógica
├── .nojekyll                      # Flag para evitar compilación con Jekyll
└── README.md                      # Documentación del repositorio
```
